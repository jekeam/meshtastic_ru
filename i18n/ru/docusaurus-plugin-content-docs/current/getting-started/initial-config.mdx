## Настройка региональных параметров {#set-regional-settings}

Чтобы начать общение по mesh-сети, необходимо установить ваш регион. Этот параметр определяет, какой частотный диапазон использует ваше устройство, и должен быть установлен в соответствии с вашим географическим местоположением.

<TabItem value="android">

#### Android

1. Следуйте инструкциям по [установке](/docs/software/android/installation) и [использованию](/docs/software/android/usage/) для [Meshtastic Android](/docs/category/android-app).
2. Откройте приложение, подключитесь к устройству с вашего телефона через USB Serial или Bluetooth.
3. После сопряжения и подключения нажмите **УСТАНОВИТЬ РЕГИОН (SET YOUR REGION)** под карточкой подключенного устройства. Или перейдите в **Настройки (Settings) > LoRa**.
4. Выберите регион из списка в соответствии с вашим географическим местоположением. Нажмите **Отправить (Send)**

</TabItem>
<TabItem value="apple">

#### Apple

:::info
Конфигурация Региона (Region), Модемных пресетов (Modem Preset) и Лимита хопов (Hop Limit) доступна на iOS, iPadOS и macOS в разделе Настройки (Settings) > Конфигурация радио (Radio Configuration) > LoRa.
:::

</TabItem>
<TabItem value="cli">

#### CLI

1. Установите [Meshtastic PythonCLI](/docs/software/python/cli/installation)
   ```sh
   pip3 install --upgrade pytap2
   pip3 install --upgrade meshtastic
   ```
2. Выполните следующую команду, заменив `<REGION-CODE>` на код региона из списка выше в соответствии с вашим географическим местоположением.
   ```sh
   meshtastic --set lora.region <REGION-CODE>
   ```

</TabItem>
<TabItem value="web">

#### Web

1. Откройте Meshtastic Web интерфейс: [client.meshtastic.org](https://client.meshtastic.org)
2. Перейдите в меню **LoRa**.
3. В разделе **Региональные настройки (Regional Settings)** установите ваш **Регион (Region)** в соответствии с вашим географическим местоположением.
4. Нажмите **Сохранить (Save)**.

</TabItem>
</Tabs>
